# COLD BREW · Гранат 280 мл

Векторный логотип и макет печати на стекле для кофейного тонизирующего напитка.

Figma: https://www.figma.com/design/OikHQDX3SQJGcWjbTTX82w

## Логотип — `logo/`

Перерисован в вектор с варианта №18 «Энерго-минимализм»: прямые и скругления
построены геометрически по исходнику, буквы в кривых, шрифт не нужен.

| Файл | Для чего |
|---|---|
| `cold-brew-logo.svg` / `.png` | основной: белые буквы + металлическая тень на изломе молнии, прозрачный фон |
| `cold-brew-logo-on-black.svg` / `.png` | то же на чёрной подложке |
| `cold-brew-logo-mono-white.svg` / `.png` | один цвет (белый) — для трафаретной печати |
| `cold-brew-logo-mono-dark.svg` / `.png` | один цвет (#1A1210) — для светлого фона |

PNG — 4096 px по ширине.

## Печать на бутылке — `label/`

`cold-brew-granat-print.svg` — макет печати: логотип вертикально по центру
(читается снизу вверх), внизу «Кофейный тонизирующий напиток», рубиновая
плашка «ГРАНАТ» и «280 мл». Весь текст переведён в кривые.

- Масштаб: 10 px = 1 мм; поле печати 39,6 × 91,8 мм.
- Размеры рассчитаны на бутылку Ø ≈ 54 мм (оценка по фото для 280 мл) —
  перед печатью подгоните под реальный диаметр.
- Цвета: белая краска `#FFFFFF`, рубиновый `#B8162F` → `#8A0F22` (градиент плашки).
- Металлическая тень на молнии — серый градиент; для печати в одну краску
  используйте `logo/cold-brew-logo-mono-white.svg`.

## Шрифты

- Russo One — «ГРАНАТ», «280 мл» (с наклоном 15°, как у логотипа)
- Exo 2 SemiBold Italic — «Кофейный тонизирующий напиток»

Оба шрифта бесплатные (Google Fonts) и поддерживают кириллицу.

## Мокапы

Фото-мокапы (бутылка с колд брю и прозрачная) не лежат в репозитории, потому что
на них ваше личное фото, а репозиторий публичный. Их прислали отдельными PNG.

## Исходники — `_src/`

Скрипты, которыми собраны этикетка и мокапы (Python 3, Pillow, NumPy, SciPy,
CairoSVG, uharfbuzz, fontTools):

- `label.py` — макет печати (положение логотипа, размеры текста, цвет плашки);
- `textpath.py` — набор текста в кривые; шрифты положить в `_src/fonts/`
  как `RussoOne.ttf` и `Exo2_600i.ttf`;
- `bottle_geom.py` — модель камеры и цилиндра бутылки на фото;
- `mockup.py`, `coffee.py` — мокап на прозрачной бутылке и с напитком
  (нужен исходный снимок бутылки как `photo.png`).
